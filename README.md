# Armello 简体中文重译汉化补丁

> **Pre-Release v0.3**：提供三个版本——
> - **font 版**（308MB）：汉化文本 + 中文字体替换（正文=霞鹜文楷，标题=思源宋体 Heavy，主菜单=霞鹜文楷）
> - **artfont 版**（271MB）：汉化文本 + 毛笔楷书艺术字（正文与主菜单=马善政）
> - **textonly 版**（42MB）：仅汉化文本，保持官方原字体
>
> 从 [Releases](https://github.com/deserthouse/armello-chinese-localization/releases) 下载；font 版与 artfont 版含三个文件，需分别覆盖到不同目录，详见压缩包内安装说明。

非官方简体中文全量重译。基于官方中文的机翻问题，对游戏内 **10,867 条**文本逐条对照英文原文重新翻译与审校，覆盖任务剧情、卡牌、物品、UI、成就、对话等全部内容。

## 🎮 安装

**所有版本安装方式相同：把压缩包内全部内容解压到游戏的 `armello_Data` 文件夹，覆盖同名文件即可。**

> 游戏目录找法：Steam 库中右键 Armello → 管理 → 浏览本地文件 → 进入 `Armello\armello_Data\`
>
> 压缩包内的 `StreamingAssets` 子文件夹会自动落到正确位置，无需手动操作。建议覆盖前备份原文件。

## ❓ 常见问题

**问：游戏更新后补丁会失效吗？**

答：游戏大版本更新后文本结构可能变化，届时需要等本补丁适配新版。若更新后出现异常，先还原官方中文。

**问：会影响成就或联机吗？**

答：不会。补丁只替换显示文本，不修改任何游戏逻辑与数值。

**问：font 版和 artfont 版有什么区别？**

答：文本内容完全相同，区别仅在于字体风格——font 版正文用霞鹜文楷（清爽手写楷体），artfont 版用马善政毛笔楷书（粗犷书法风）。选你喜欢的即可，不要混装。

**问：发现错别字或翻译问题？**

答：欢迎提 Issue，注明大概位置（哪个界面/哪张卡/哪段剧情）即可。

## ✅ 质量保障

全部 10,867 条文本经 **多轮 AI 引擎审校**，最终由 DeepSeek Pro（思考模式）拉通英文原文、官方中文与补丁新译文进行三方综合审查，择优选用的 **AI 精校版文本**。术语统一执行 GLOSSARY 与 STYLE_GUIDE 规范，占位符与格式标签经程序化校验。AI 精校虽已大幅降低错漏率，但个别错漏仍无法完全避免，欢迎通过 Issue 反馈。

## 🖋 字体工程

**主菜单字体替换原理**：Armello 的主菜单文字不走游戏内常规的动态字体（TTF），而是走 TextMeshPro（TMP）的 SDF 图集渲染——每个字形预烘焙为带符号距离场（Signed Distance Field）的像素图，打包在游戏资源包内。本补丁将游戏自带的 Noto Sans CJK SC 图集（2,048×2,048 像素，2,752 个字形）逐字替换为目标字体的 SDF 烘焙版本，保持原始图集布局不变以兼容引擎的字符查找表。替换需要在 `gamedatabase.unity3d`（离线渲染路径）和 `resources.assets`（在线渲染路径）两处同步生效。

**游戏内正文与标题**：通过替换游戏资源中的 Font 对象内嵌 TTF 数据实现——正文槽位（Regular/Bold）替换为目标字体子集（按游戏全部语料 3,120 字子集化，含从其他开源字体移植的 9 个缺失字符），标题槽位保持思源宋体 Heavy。

**字体选用原则**：
- **开源许可**：仅使用 OFL / SIL OFL 1.1 等可自由分发的字体（霞鹜文楷、思源宋体、马善政均为此类）
- **风格适配**：正文需长时间阅读，选清爽易读的手写楷体（霞鹜文楷）；艺术字版选有视觉冲击力的毛笔楷书（马善政）以匹配 Armello 的中世纪奇幻画风
- **字符覆盖**：字体必须覆盖游戏全部语料字符，经程序化验证零缺失后才打包
- **体积控制**：按语料精确子集化（不打包全量字体），控制补丁体积
