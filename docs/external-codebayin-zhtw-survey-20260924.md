# 外部调研:codebayin/Armello.zh_TW(2015 粉丝繁中)评估存档

> 调研日期:2026-09-24。来源:外部资源普查(完整版见 armello-android-revived 仓 `knowledge/external/codebayin-zhtw-assessment-20260924.md`)。
> 本文档只保留对本项目有用的部分。

## 它是什么(纠正表面认知)

- GitHub 显示"2017-04 更新、1 commit"均为假象:真实历史 **98 commits,2015-10 → 2016-01 活跃**,4+ 人 fork/PR 协作,抢先体验期粉丝繁中,**早于官方繁中**。
- 工作流:2015 年游戏无繁中语言位,把繁译**写进 English 槽**(`English.txt` 实为繁中);`SimplifiedChinese.txt` 是当时官简导出参考。README 起因自述"只有簡中翻譯且翻譯品質低落"——**官简质量差在 2015 年就已是社区共识**(简中线全量重译正当性的时间线佐证)。

## 完整度与质量(实测)

- 8,028 键中翻 2,102(**26.2%**):UI 91%/聊天轮盘全/成就全/卡牌 65%/教程 ACT1-3 高但 ACT4 仅 10/80/任务对白 4%。由外向内推进,死在 2016-01。
- 文风与术语一致性佳;**实锤数值/语义错约 5 条,全部集中在装备/诡计卡描述**:

| ID | 英文原义 | codebayin 译 | 错误类型 |
|---|---|---|---|
| CARD_TRK17_DESCRIPTION | −4 Magic **and −1 Action Point** | −4點魔法值 | 漏译 −1 AP |
| CARD_ITM27_DESCRIPTION | 战斗 +1 剑;防御时再 +1 剑 | 防禦時+2寶劍 | 丢攻击阶段 +1 |
| CARD_ITM31_DESCRIPTION | +1 剑 +1 骰 | +2骰子 | 剑误为骰 |
| CARD_ITM30_DESCRIPTION | +1 盾 + Reflect | +1生命力且+1盾 | 凭空多体力;Reflect 丢 |
| ACH_100_031_TITLE | Baned-Aid(双关) | OK,崩 | 烂尾恶搞 |

**⚠️ 重要限定:以上错译在 codebayin 的 2015 粉丝译本里,不代表官繁同样错。** 价值=同类风险清单:装备/诡计卡数值描述是错译重灾区,建议繁中精修线对官繁的上述同 ID 条目跑一次数值核对(提取 EN 与译文的数字集合比对,方法论已在评估中验证)。

## 术语体系对照(对 GLOSSARY_TC 的旁证)

codebayin 自成一套 2015 台版术语:**Bane=厄魔 / Rot=墮落 / Wyld=大地之母 / Prestige=威望**,人名意译(Thane=賽恩、River=莉芙)。与官繁(魔鴆/汙穢/懷爾德/音译)完全是两套体系。旁证结论:

- 台版玩家认知已被官繁覆盖,2015 粉丝体系无存量用户——**支持 GLOSSARY_TC 乙表"跟官繁走"的裁决**(Rot=汙穢、Bane=魔鴆 等不必因"社区既有译法"动摇)。
- 但"厄魔/墮落"式语义造词证明了台版社区对这批词的语义理解路径,若未来审校遇到官繁语义存疑条目,可作第二意见参照。

## 对本项目的其他价值

- **数值自动核对脚本思路**(EN/译文数字集合比对,先剥离 `<placeholder>`)可直接并入 pipeline QA——本次评估用它在 1,914 条里 20 分钟定位全部疑点,比人工抽检可靠。
- 其 README 的协作纪律(全形标点手册/术语 wiki/PR 流程)与本项目 STYLE_GUIDE 体系同构,无新增可学。
- 官方简中"品質低落"的 2015 年社区一手证据(README 原文),可用于回应"为什么不基于官中修"的问询。
